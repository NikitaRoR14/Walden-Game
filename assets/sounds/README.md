# Sound Assets

This folder should contain the following sound files for the game:

## UI Sounds
- `button_click.mp3` - Sound when clicking a button
- `button_hover.mp3` - Subtle sound when hovering over a button
- `menu_open.mp3` - Sound when opening a menu
- `menu_close.mp3` - Sound when closing a menu

## Fishing Sounds
- `cast_line.mp3` - Sound of casting the fishing line
- `water_splash.mp3` - Bobber hitting the water
- `reeling.mp3` - Sound of reeling in (optional)
- `fish_caught.mp3` - Success sound when catching a fish

## Dialog Sounds
- `dialog_open.mp3` - Dialog box appearing
- `text_type.mp3` - Subtle typing sound for typewriter effect

## Ambient/Background Sounds (Loop)
- `birds.mp3` - Bird chirping (looping)
- `water_ambient.mp3` - Gentle water sounds (looping)
- `wind.mp3` - Soft wind ambiance (looping)
- `background_music.mp3` - Calm, meditative background music (looping)

## Sound Recommendations

For a cozy Thoreau-inspired game, sounds should be:
- **Gentle and natural** - Avoid harsh or jarring sounds
- **Calming** - Match the contemplative mood
- **Short UI sounds** - 0.1-0.3 seconds for clicks/hovers
- **Ambient loops** - 30-60 seconds minimum for seamless looping

## Free Sound Resources

You can find royalty-free sounds at:
- **Freesound.org** - Community-uploaded free sounds
- **OpenGameArt.org** - Game-specific assets
- **ZapSplat.com** - Free sound effects library
- **Incompetech.com** - Royalty-free music by Kevin MacLeod

## File Format

- MP3 format is recommended for broad browser support
- OGG can be used as an alternative
- Keep file sizes reasonable (< 1MB per sound effect, < 5MB for music)

## Note

The game will work without these files - it will simply fail silently. Add sound files to enhance the experience, but the game is fully playable without them.
